=== POURQUOI JE REFUSE DE GELER ===
Une seule propriete requise n'est PAS evaluable dans l'etat actuel du code :

  P8 -- LA COLLECTE WHT ET SES CRITERES DE COUVERTURE NE SONT PAS VERIFIES
        COMME RACCORDES DANS LE CODE FINAL.

La consigne est explicite : « Verifier dans le code final que la collecte WHT et
ses criteres de couverture sont reellement raccordes. Leur conception ancienne
ou leurs tests isoles ne suffisent pas. » Je n'ai PAS effectue cette
verification. Une collection WHT non raccordee rendrait P3 et P4 -- rotation
candidate et propriete negative de rotation baseline -- non evaluables, et ces
deux proprietes figurent au contrat.

Le protocole v2 est REDIGE et coherent. Le gel est refuse NON PAS parce que le
protocole serait mauvais, mais parce qu'une de ses exigences ne serait pas
honorable avec le raccordement actuel. Geler maintenant reviendrait a masquer ce
point -- exactement la faute que ce dispositif existe pour empecher.

=== PREUVE QUE LE PLAN N EST PAS UN JSON DOCUMENTAIRE ===
La consigne exige que le point d entree applique REELLEMENT le plan. Etat exact :
  - APPLIQUE dans le code : la garde avant tout calcul ; le maximum de tokens
    (requete -> run_pipeline -> boucle bornee) ; le contrat d arret (EOS, limite,
    aucun decode apres arret) ; l argmax au plus petit ID ; le refus des logits
    invalides ; l isolement des destinations de capture ; les compteurs de sortie.
    Ces elements sont TESTES dans le binaire courant (7 controles d arret,
    6 cas de refus du point d entree, 41 + 42 controles des suites).
  - NON ENCORE APPLIQUE : la SEQUENCE baseline1 -> candidat1 -> baseline2 ->
    candidat2 elle-meme. Le point d entree n execute qu UN run par invocation
    (`--mode real-preflight`) et n enchaine ni les quatre runs, ni la
    revérification des identites avant chacun, ni l arret de sequence.
  => PREFLIGHT_PLAN_ENFORCED_BY_ENTRYPOINT=PARTIAL. Les REGLES du plan sont
     appliquees et testees ; son ORCHESTRATION sur quatre runs reste a ecrire.
     C est un second bloqueur, plus modeste, mais reel et nomme.
