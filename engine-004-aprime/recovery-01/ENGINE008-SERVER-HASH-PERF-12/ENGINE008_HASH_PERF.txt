ENGINE-008 -- REDUIRE LE COUT SHA256 SANS AFFAIBLIR L'INTEGRITE
==========================================================================
SUBSTITUTION PAR OPENSSL : x11,27 SUR LE BLOB, x10,77 SUR LE MODELE.
EMPREINTES STRICTEMENT IDENTIQUES. AUCUN CONTROLE RETIRE.
VALIDATION SERVEUR : 3 PAIRES, LOGITS BINAIREMENT IDENTIQUES.

=== 1. COUT DE L'IMPLEMENTATION PRECEDENTE ===
  `obrain-sha256.h` etait une implementation AUTOPORTANTE, appelee via
  `hex_of` (blob en memoire) et `hex_of_file` (modele, lecture par blocs).
  Decomposition : ~201 Mo/s sur aarch64, soit **798,6 ms pour 160 697 016
  octets**. La lecture du fichier est deja sequentielle par blocs de 1 Mio et
  le hachage ne copie pas le blob : **le cout est donc le CALCUL PUR**, sans
  acceleration materielle. La conversion hexadecimale ne porte que sur 32
  octets : elle est negligeable.
  **Le processeur dispose des extensions SHA ARMv8** (verifie : `armv8-a+crypto`
  compile), que cette implementation n'utilisait pas.

=== 2. DEPENDANCE CHOISIE ET SON LINKAGE REEL ===
  **OpenSSL 3.0.13** (`libcrypto.so.3`), implementation EPROUVE, EN PROCESSUS.
  Aucun nouveau SHA256 artisanal, aucun sous-processus.
  `LIBCRYPTO_SHA256=6facd87aa596f6d10c2029802756c56cef8761576a3e8894c42a7295a5a89d75`
  Linkage VERIFIE : `libcrypto.so.3 => /lib/aarch64-linux-gnu/libcrypto.so.3`
  (present dans `ldd libllama-server-impl.so`). CMake : `find_package(OpenSSL
  REQUIRED)` + `OpenSSL::Crypto` + `-DOBRAIN_USE_OPENSSL_SHA256` sur la cible
  `server-context`.
  **La REFERENCE autoportante reste compilee et accessible** (`hex_of_ref` /
  `hex_of_file_ref`) : elle sert de comparaison et de repli si OpenSSL n'est pas
  active. Le basculement se fait par une seule macro.

Sha256_OUTPUT_UNCHANGED=YES
  Aucun appel n'a change : `kv_sha256_hex`, `kv_sha256_hex_file`,
  `sha256_hex_file`, `kv_model_sha256` appellent tous `obrain_sha::hex_of*`.
  **Le hachage n'a PAS ete deplace sous le verrou global** (l'identite modele
  est calculee hors verrou, au chargement, et le blob est hache hors du verrou
  du cache).
  **La verification a l'import n'a PAS ete supprimee** : elle tourne toujours,
  simplement plus vite.
