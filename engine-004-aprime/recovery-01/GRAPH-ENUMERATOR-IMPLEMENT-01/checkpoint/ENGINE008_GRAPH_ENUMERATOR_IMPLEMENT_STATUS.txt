=== CORRECTION DE DEUX DEFAUTS REELS TROUVES PAR LES TESTS ===
D1. ggml separe leafs[] et nodes[]. Aucun accesseur de leafs n'est exporte.
    Ma premiere version comptait toute source hors nodes[] comme reference NON
    RESOLUE, ce qui rendait COMPLETE inatteignable. Corrige par le critere
    STRUCTUREL ggml : une feuille a op == GGML_OP_NONE (ggml.h:489).
    - source dans nodes[]      -> index local
    - source hors nodes[] ET op == GGML_OP_NONE -> FEUILLE legitime (-1)
    - source hors nodes[] ET op != NONE         -> calcule mais absent (-2),
                                                   seule vraie reference non resolue
    LIMITE DECLAREE : les feuilles sont observees a travers src[], PAS
    enumerees independamment (aucun accesseur de leafs n'existe).
D2. submit_events_expected / observed etaient declares `bool` alors que ce sont
    des COMPTES : 3 et 1 devenaient tous deux `true`, et la perte de soumissions
    intermediaires n'etait jamais detectee. Corrige en `int`.

=== CLASSIFICATION NextN : LE POINT IMPORTANT ===
L'enumeration est STRUCTURELLE et fonctionne : elle observe les feuilles
consommees par les operations, resout les dependances, et serialise 27 champs.

MAIS la SEULE signature NextN disponible dans Q1 est une CONVENTION DE NOM
(blk.<N>.nextn.*). Un nom n'est pas une structure. Aucune regle
d'identification STRUCTURELLE n'est justifiee par la cartographie source.

CONSEQUENCE ASSUMEE : le classificateur REFUSE DE TRANCHER.
  NEXTN_STRUCTURE_DETECTED  : jamais rendu -- il faudrait une regle justifiee
  NEXTN_NOT_DETECTED_IN_COMPLETE_SUBMITTED_GRAPH_SCOPE : jamais rendu non plus
  A la place : NOT_CONFIRMED_IDENTIFICATION_RULE_INSUFFICIENT
  Les indicateurs de nom restent exportes comme OBSERVATIONS BRUTES
  (nextn_leaf_count, nextn_op_count), jamais comme conclusion.

C'est exactement l'exigence « une regle positive doit reposer sur la structure,
pas seulement sur une sous-chaine ». Mon premier jet la violait : le test
« nom trompeur » a echoue et l'a revele. Je n'ai pas ajuste le test pour le
faire passer ; j'ai corrige la regle, et le test verifie desormais que le
classificateur ne conclut RIEN.
